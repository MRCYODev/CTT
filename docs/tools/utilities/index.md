# Utilities

A collection of useful utilities for system maintenance, troubleshooting, optimization, networking, storage management, and everyday tasks.

| Tool | Description | Supported platforms |
| --- | --- | --- |
| [WinUtil](https://github.com/ChrisTitusTech/winutil) | Windows utility for system configuration, optimization, troubleshooting, and software installation. | <PlatformBadges items={['windows']} /> |
| [ShutUp10++](https://www.oo-software.com/en/shutup10) | Helps manage Windows privacy and telemetry-related settings. | <PlatformBadges items={['windows']} /> |
| [LinUtil](https://github.com/ChrisTitusTech/linutil) | Linux utility for system setup, maintenance, troubleshooting, and configuration. | <PlatformBadges items={['linux']} /> |
| [Ninite](https://ninite.com/) | Installs and updates multiple popular Windows applications automatically. | <PlatformBadges items={['windows']} /> |
| [Chocolatey](https://chocolatey.org/) | Windows package manager for installing, upgrading, and managing software from the command line. | <PlatformBadges items={['windows']} /> |
| [Snappy Driver Installer Origin](https://www.snappy-driver-installer.org/) | Offline-capable tool for installing and updating Windows device drivers. | <PlatformBadges items={['windows']} /> |
| [Driver Store Explorer](https://github.com/lostindark/DriverStoreExplorer) | Manages the Windows Driver Store and helps remove outdated or unnecessary driver packages. | <PlatformBadges items={['windows']} /> |
| [WinDirStat](https://windirstat.net/) | Visualizes disk usage to help identify files and folders consuming storage space. | <PlatformBadges items={['windows']} /> |
| [WizTree](https://diskanalyzer.com/) | Fast disk space analyzer for finding large files and folders. | <PlatformBadges items={['windows']} /> |
| [Bulk Crap Uninstaller](https://www.bcuninstaller.com/) | Removes unwanted applications and leftover files, including software that is difficult to uninstall normally. | <PlatformBadges items={['windows']} /> |
| [Recuva](https://www.ccleaner.com/recuva) | Recovers deleted files from hard drives, SSDs, USB drives, memory cards, and other storage devices. | <PlatformBadges items={['windows']} /> |
| [Disk Drill](https://www.cleverfiles.com/data-recovery-software.html) | Data recovery and disk management utility for recovering lost or deleted files. | <PlatformBadges items={['windows', 'macos']} /> |
| [TeamViewer](https://www.teamviewer.com/) | Remote access and remote support software for connecting to computers and mobile devices. | <PlatformBadges items={['windows', 'linux', 'macos', 'android']} /> |
| [AnyDesk](https://anydesk.com/) | Lightweight remote desktop software for remote access, support, and administration. | <PlatformBadges items={['windows', 'linux', 'macos', 'android']} /> |
| [GParted](https://gparted.org/) | Partition editor for creating, resizing, moving, copying, and managing disk partitions. | <PlatformBadges items={['linux', 'bootable']} /> |
| [BleachBit](https://www.bleachbit.org/) | Cleans unnecessary files, caches, logs, and other system data to free disk space. | <PlatformBadges items={['windows', 'linux', 'macos']} /> |
| [Wireshark](https://www.wireshark.org/) | Network protocol analyzer for capturing and inspecting network traffic. | <PlatformBadges items={['windows', 'linux', 'macos']} /> |
| [NetCut](https://arcai.com/netcut/) | Network management utility for viewing and managing devices connected to a local network. | <PlatformBadges items={['windows', 'android']} /> |
| [elmoCut](https://github.com/elmoiv/elmocut) | Android network utility for discovering and managing devices on a local network. | <PlatformBadges items={['android']} /> |
