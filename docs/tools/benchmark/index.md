# Benchmark

Benchmarking and performance-testing software and reference results for CPUs, GPUs, memory, storage, games, and whole systems.

## Benchmark Software

| Tool | Description | Supported platforms |
| --- | --- | --- |
| <><SourceBadge url="https://www.ocbase.com/" /> [OCCT](https://www.ocbase.com/)</> | Stability testing and hardware monitoring suite with CPU, GPU, memory, power, and system tests. | <PlatformBadges items={['windows']} /> |
| <><SourceBadge url="https://geeks3d.com/furmark/" /> [FurMark](https://geeks3d.com/furmark/)</> | GPU stress-testing and benchmarking tool designed to test graphics stability and thermal behavior. | <PlatformBadges items={['windows']} /> |
| <><SourceBadge url="https://silver.urih.com/" /> [SilverBench](https://silver.urih.com/)</> | Browser-based benchmark for measuring JavaScript and CPU performance. | <PlatformBadges items={['web']} /> |
| <><SourceBadge url="https://www.userbenchmark.com/Software" /> [UserBenchmark](https://www.userbenchmark.com/Software)</> | Windows benchmark that compares system components against other submitted results. | <PlatformBadges items={['windows']} /> |
| <><SourceBadge url="https://www.geekbench.com/" /> [Geekbench](https://www.geekbench.com/)</> | Cross-platform benchmark for CPU and GPU workloads. | <PlatformBadges items={['windows', 'linux', 'macos', 'android']} /> |
| <><SourceBadge url="https://www.3dmark.com/" /> [3DMark](https://www.3dmark.com/)</> | Benchmark suite for measuring gaming and graphics performance. | <PlatformBadges items={['windows', 'android']} /> |
| [CrystalDiskMark](https://crystalmark.info/en/software/crystaldiskmark/) | Storage benchmark for sequential and random read/write performance. | <PlatformBadges items={['windows']} /> |
| [Prime95](https://www.mersenne.org/download/) | CPU stress-testing and stability-testing utility based on Prime search workloads. | <PlatformBadges items={['windows', 'linux', 'macos']} /> |
| [MangoHUD](https://github.com/flightlessmango/MangoHud) | Vulkan and OpenGL overlay for monitoring performance statistics such as FPS, frame time, CPU, and GPU usage. | <PlatformBadges items={['linux']} /> |
| [Fraps](https://fraps.com/) | Windows benchmarking and frame-rate monitoring utility for games and 3D applications. | <PlatformBadges items={['windows']} /> |
