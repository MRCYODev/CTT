# Contributing to CTT

:::warning
 **CTT is currently under construction.**

CTT is being built as a community-driven technical resource covering **modding, repair, troubleshooting, diagnostics, customization, and maintenance** across many types of technology.

As the project grows, we will need contributors to help expand and maintain the documentation.
:::


## 🤝 Want to help?

**We'd love your contribution.**

You can help CTT by:

- Writing new guides and tutorials
- Adding repair and troubleshooting procedures
- Adding useful tools and software
- Documenting console and handheld modifications
- Adding PC and operating-system guides
- Documenting mobile devices and software
- Adding networking and router information
- Testing procedures and verifying instructions
- Finding and fixing broken or outdated links
- Correcting mistakes and improving existing documentation
- 💡 Suggesting new categories, tools, and features

## 👥 Who can contribute?

You don't need to be a professional technician or developer.

CTT can benefit from people with experience in:

- PC hardware
- Windows, Linux, and other operating systems
- Android and mobile devices
- Game consoles and handhelds
- Networking and routers
- Hardware repair and electronics
- Software and system administration
- Modding and customization
- Cybersecurity and system security
- Retro hardware
- Troubleshooting and diagnostics

If you know something useful that isn't documented yet, **you can help add it.**

## 🛡️ Quality & Safety

CTT aims to provide information that is **accurate, useful, and safe to follow**.

Before contributing, please:

- Verify information before submitting it.
- Test procedures whenever possible.
- Specify the device, model, version, or firmware when relevant.
- Clearly mention potential risks.
- Don't submit malicious software or unsafe procedures.
- Don't copy copyrighted documentation without permission.
- Prefer official sources when referencing downloads, firmware, or documentation.

## 🚧 We're still building

Some parts of CTT are incomplete and more sections will be added over time.

If you find something missing, outdated, incorrect, or broken, **please let us know or contribute a fix.**

## ❤️ Help us build CTT

Whether you want to add a complete guide, fix a typo, test a procedure, or suggest an improvement - **every contribution helps.**
